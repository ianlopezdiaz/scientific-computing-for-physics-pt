# Computação Científica para Física

> **Idioma:** 🇧🇷 Português | 🇺🇸 [English](https://github.com/ianlopezdiaz/scientific-computing-for-physics)

Uma introdução moderna à Computação Científica para estudantes de Física e Engenharia utilizando Python.

Este repositório reúne materiais didáticos, notebooks interativos e exemplos computacionais desenvolvidos para ensinar Física por meio da programação científica, da análise de dados, da visualização e dos métodos numéricos.

O objetivo não é apenas ensinar Python ou implementar algoritmos, mas mostrar como as ferramentas computacionais fazem parte da prática científica moderna.

Este projeto está sendo desenvolvido continuamente e pretende evoluir ao longo do tempo até se tornar um recurso educacional completo para disciplinas de graduação em Física e Engenharia.

---

## Objetivos

Os principais objetivos deste projeto são:

* Introduzir a Computação Científica utilizando Python.
* Ensinar programação aplicada à resolução de problemas de Física.
* Desenvolver a capacidade de analisar e visualizar dados científicos.
* Apresentar métodos numéricos de forma gradual e contextualizada.
* Complementar o ensino tradicional de Física com experimentos computacionais.
* Servir como material de apoio para disciplinas de graduação.
* Produzir um recurso educacional aberto, gratuito e continuamente atualizado.

---

## Filosofia do Projeto

A Computação Científica tornou-se uma ferramenta indispensável para físicos, engenheiros e pesquisadores.

Ao longo da graduação, os estudantes entram em contato com diferentes tipos de problemas computacionais:

* análise de dados experimentais;
* simulações numéricas;
* visualização científica;
* resolução de equações diferenciais;
* ajuste de modelos;
* tratamento estatístico de dados;
* produção de gráficos para relatórios e artigos científicos.

Este projeto procura integrar todos esses aspectos em uma única trilha de aprendizagem.

Em vez de ensinar programação separadamente, Python é apresentado como mais uma ferramenta para compreender fenômenos físicos, construir modelos computacionais e analisar resultados.

---

## Organização do Projeto

O material está organizado em quatro grandes partes.

### Parte I — Computação Científica

Introdução às principais ferramentas utilizadas em Computação Científica com Python.

Entre os tópicos abordados estão:

* Python
* Jupyter Notebooks
* NumPy
* Pandas
* Matplotlib
* SciPy
* Organização de projetos científicos

---

### Parte II — Física e Ciência de Dados

Esta seção apresenta conceitos fundamentais de análise de dados científicos, com foco nas necessidades de estudantes de Física e Engenharia.

Os notebooks abordam temas como:

* análise de dados experimentais;
* visualização científica;
* estatística descritiva;
* incertezas experimentais;
* ajuste por mínimos quadrados;
* regressão linear e não linear;
* comunicação de resultados científicos.

---

### Parte III — Física

A maior parte do projeto é dedicada às disciplinas tradicionais da graduação.

Os conteúdos seguem aproximadamente a sequência de um curso universitário:

* Física I — Mecânica Clássica
* Física II — Ondas, Fluidos e Termodinâmica
* Física III — Eletricidade e Magnetismo
* Física IV — Óptica e Física Moderna

Cada notebook combina teoria, implementação computacional, visualizações, simulações e exercícios.

Sempre que possível, métodos numéricos são introduzidos naturalmente como ferramentas para resolver problemas físicos.

---

### Parte IV — Métodos Numéricos

Os algoritmos utilizados ao longo do projeto são reunidos nesta seção, onde são estudados de forma mais aprofundada.

Entre os tópicos previstos estão:

* diferenciação numérica;
* integração numérica;
* busca de raízes;
* interpolação;
* sistemas lineares;
* equações diferenciais ordinárias;
* equações diferenciais parciais;
* métodos de Monte Carlo;
* otimização.

Essa organização permite manter os capítulos de Física focados na interpretação dos fenômenos, enquanto os detalhes matemáticos e computacionais dos algoritmos ficam concentrados em um material de referência.
